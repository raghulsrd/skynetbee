Privacy Policy

NoteVault

1. About NoteVault

NoteVault is a secure personal storage application where users can save passwords, private notes, email credentials, secrets, and important personal information safely on their device.

2. User Privacy

We do not collect, track, or share any personal information from users.

  • No personal data is collected.
  • No user information is shared with third parties.
  • No activity tracking is performed inside the app.

3. Local Storage & Security

All data saved inside NoteVault is stored only on the user’s local device database/storage.

Your information is not uploaded to external servers or cloud storage.

User passwords are protected using SHA-32 encryption technology to improve security and help keep stored passwords safe from unauthorized access.

4. App Protection Features

  • The app is protected using a password created by the user.
  • Users can change their password anytime from Settings.
  • Deleted items can be recovered from the Deleted Items section if removed accidentally.

5. User Responsibility

Users are responsible for keeping their password secure. We recommend not sharing your password with anyone to protect your personal information.

6. Policy Updates

This Privacy Policy may be updated in future versions of NoteVault. Any changes will be reflected on this page.
